# v0.0.14 — Read-only trophy data integrity checkpoint

**Status:** source committed; CI compilation and PS3 console test not yet verified.

## Implementation
- Read only Persona 5 set `NPWR11866_00`.
- Safely open `TROPUSR.DAT` with `SYS_O_RDONLY`; reject files above 4 MiB.
- Stream up to 4 KiB at a time and compute FNV-1a 64-bit fingerprint for before/after comparison.
- Log file byte count and hash only into existing app-owned diagnostic report.
- On errors or short reads, log incomplete status. Do not touch or repair the trophy file.
- Preserve previous id-11 metadata checks and output `trophy_11_state=UNKNOWN`.

## What this establishes
If logs show a complete read and a stable hash, we have repeatable evidence the observed bytes did not change between tests. FNV-1a is a non-cryptographic fingerprint and does **not** validate signatures or trophy-state layouts.

## What it does NOT establish
No individual trophy-state decoder, native context registration, unlock operation, or PSN sync is implemented or verified. This is a diagnostic prerequisite, **not** a working unlocker.
