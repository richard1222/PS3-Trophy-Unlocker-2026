# v0.0.15 — Experimental read-only ID 11 state check

Source commit: a503feba. **Not yet compiled or tested on hardware.**

The console probe attempts to read and validate the type-4 and type-6 records in Persona 5's decoded TROPUSR.DAT with bounded lengths, explicit big-endian integers, per-entry headers, distinct trophy IDs and exact ID 11 lookup. It uses the same assumed layout as the existing host inspector (`tools/inspect_trophy.py`).

Output can report LOCKED or UNLOCKED only when both target entries pass its present checks. **This is provisional file-parser output, not independently verified console truth.** The report labels its source `decoded_tables_unverified_on_retail`. On incompatible layout or read error it reports UNKNOWN.

No native trophy context has yet been created; no unlock function is called. No file changes except app-owned diagnostic logs. PSN sync remains out of scope.
