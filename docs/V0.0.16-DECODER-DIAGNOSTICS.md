# v0.0.16 — Read-only trophy decoder diagnostics

The v0.0.15 PS3 log showed `state_parse=UNSUPPORTED_OR_INVALID error=0x00000000`, without enough detail to explain the rejected layout. The v0.0.16 probe now records a specific `reason`, `table`, and `entry` for rejected structural checks. Outcomes remain provisional. No trophy writes, unlock API, memory modification, or PSN synchronization was added.

## Test instructions
1. Build latest `main` with GitHub Actions and confirm green.
2. Install the new `trophy-startup.pkg`, launch PS3 Trophy Browser, and press OK to scan Persona 5.
3. Locate the latest `trophy-probe-diag-###.txt` in `/dev_hdd0/game/TROPH2026/USRDIR/` (or fallback `/dev_hdd0/tmp/troph2026/`).
4. Upload the file to Google Drive. Confirm `probe_version=0.0.16-diagnostics` and inspect the `trophy_11_state` line.

This version does **not** prove native trophy context registration or reliable trophy-state decoding. Do not act on a parsed locked/unlocked value until independently verified.
