# PS3 Trophy Unlocker 2026 — v0.0.6 Read-Only Beta

**Release status:** Public release notes published; verified installation PKG **not yet publicly attached**. This page is not a GitHub Release object or a downloadable installer.

## Available features

- Browse installed PS3 trophy sets.
- Inspect individual trophies and their available metadata.
- Return from trophy details and exit normally.
- No trophy writes or network activity implemented by this build.

## Compatibility

The owner tested read-only browsing and normal exit on one PS3 running Evilnat 4.93 CFW. Firmware variant has not been independently confirmed. Other CFW, HEN and RPCS3 compatibility are **not** claimed.

## What is NOT supported

- Individual or bulk trophy unlocking.
- Modifying, signing, or restoring trophy files on the console.
- PlayStation Network sign-in, trophy synchronization, or unlocking trophies on an online PSN profile.

## Validation status

- Console: owner-tested read-only v0.0.6; basic browsing and exit corroborated by private diagnostics.
- Tests: 15 tests passed on a source revision reported in the private project handoff; this is not evidence that trophy modification works.
- PKG: an earlier private test build exists, but public artifact review, licensing audit, byte-for-byte checksum validation and attachment are **pending**.
- Keep console identifiers, PSN data and trophy backups out of public issue reports.
